# HOSTLY — PAID MEDIA PLAN V1

Estado: diseño y preparación. NO activar gasto todavía.

## Principio

No lanzar campañas amplias hasta que landing, medición, lead capture y CRM estén conectados. Primero instrumentar; después validar orgánico/outbound; después comprar tráfico.

## ICP inicial

Principal:
- propietario / gerente / director de restaurante
- restaurantes independientes con operación real de sala
- grupos pequeños y medianos
- negocios con sala + barra + terraza
- beach clubs y operaciones de alta complejidad

Problemas a testear:
1. demasiadas herramientas separadas
2. errores y fricción durante servicio
3. poca visibilidad de lo que ocurre en sala/cocina/barra
4. configuración y formación demasiado complejas
5. gestión del restaurante fragmentada

## Meta — Facebook / Instagram

Objetivo inicial: Leads o conversiones web, no alcance.

Estructura de prueba:
- ES | Owners-Managers | Pain Fragmentation
- ES | Owners-Managers | Service Control
- ES | Owners-Managers | Product Demo

Creatividades:
- 9:16 Reels/Stories
- 4:5 Feed
- vídeo 15–30 s
- imagen/product UI limpia

Hooks:
- "Tu restaurante no necesita cinco herramientas para funcionar."
- "Sala, cocina, barra y gestión. Un mismo sistema."
- "Un TPV pensado para el servicio real, no para complicarlo."

CTA: solicitar demo / acceso anticipado.

No usar audiencias de clientes finales ni datos operativos del restaurante.

## YouTube

Primera fase: contenido orgánico y remarketing posterior.

Formatos:
- 30–60 s: problema -> Hostly -> resultado
- demo 2–4 min
- vídeos educativos 5–10 min

Ideas:
- "Por qué un restaurante pierde tiempo usando herramientas separadas"
- "Cómo debería funcionar un TPV moderno en 2026"
- "Del pedido a cocina: así reducimos pasos durante el servicio"

## TikTok / Reels

No intentar parecer una marca corporativa tradicional.

Piezas:
- POV servicio real
- errores cotidianos de hostelería
- antes/después de un flujo
- microdemo de 15–25 s
- fundador construyendo Hostly
- features con utilidad visible

Hook en los primeros 1–2 segundos. Una idea por vídeo.

## Fases de inversión

### Fase 0 — ahora
0 € de gasto. Medición, creatividades, landing, CRM, SEO y outbound manual.

### Fase 1 — validación
Presupuesto pequeño y limitado. Buscar señal de mensaje y calidad de lead, no escalar.

### Fase 2 — repetibilidad
Solo escalar conjuntos que produzcan demos cualificadas, no simplemente clicks baratos.

### Fase 3 — expansión
Nuevas ciudades, tipos de negocio y mercados tras confirmar conversión y onboarding.

## Métricas de decisión

Primarias:
- qualified lead rate
- demo request rate
- demo show rate
- demo -> trial/early access
- trial -> activation
- CAC

Secundarias:
- CTR
- CPC
- landing CVR
- CPL

Nunca declarar una campaña ganadora solo por CTR/CPC.

## Experimentos iniciales

A. Fragmentación vs simplicidad
B. Control del servicio vs gestión integral
C. Producto visible vs founder-led
D. Demo vs acceso anticipado
E. Restaurante independiente vs grupo

Cambiar una variable importante por experimento para conservar aprendizaje.
