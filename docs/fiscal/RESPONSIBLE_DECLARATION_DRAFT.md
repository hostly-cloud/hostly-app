## Procedimiento de nueva versión

1. Clasificar si el cambio afecta comportamiento fiscal, dependencias o requisitos declarados.
2. Incrementar `HOSTLY_FISCAL_MODULE_VERSION` cuando corresponda.
3. Ejecutar unidad, integración, concurrencia, reglas, caos y XSD oficial.
4. Revisar fuentes oficiales y registrar sus versiones/fechas.
5. Completar revisión jurídica y técnica.
6. Firmar/publicar un documento individualizado y conservar histórico.
7. Configurar URL y versión; comprobar la pantalla dentro de Hostly.
8. Solo entonces habilitar el despliegue fiscal real.
